# Claude 对话离线查看器

离线浏览从 Claude 导出的对话数据。不联网，数据只在本机浏览器里读取。

## 文件

| 文件 | 用途 |
|---|---|
| `open.bat` | 检查更新后用浏览器打开查看器 |
| `index.html` + `parser.js` | 查看器本体 |
| `to-markdown.bat` | 把导出数据转成一个个 Markdown 文件 |
| `to_markdown.py` | 转换脚本（只用 Python 标准库） |

## 导出数据

1. 在电脑上用网页版或桌面版打开 Claude：设置 → 隐私 → Export data（手机 App 里没有这个按钮）。
2. 邮箱会收到下载链接，24 小时内有效，而且可能只能用一次，收到就下载。
3. 得到一个 zip，不用解压。

## 查看器

1. 双击 `open.bat`。
2. 第一次打开时选择导出的 zip（也可以拖进页面）。之后会缓存在浏览器里，再打开直接显示。
3. 左侧搜索框搜标题和全文，包括思考过程、工具调用和附件内容。回车或 ↑↓ 跳到下一处。
4. 导出数据分成多个 zip 时，用「导入更多」追加，重复的对话自动合并。

功能：按月份分组、Markdown 排版、代码块、表格、折叠的思考过程和工具调用、项目文件、记忆、复制为 Markdown、深色模式、手机宽度布局。

缓存在浏览器里，换浏览器或点「清除缓存」后需要重新选 zip。

## 转 Markdown

双击 `to-markdown.bat`，把 zip 拖进窗口后回车（或直接把 zip 拖到 bat 图标上）。zip 旁边会生成 `claude-markdown` 文件夹：

```
claude-markdown/
  _目录.md
  _记忆.md
  _projects/项目名/...
  2026-11/2026-11-20_对话标题.md
```

适合拷到 iPad 用「文件」App 或任何 Markdown 阅读器看。需要 Python 3。

## 说明

- 导出数据不含上传过的原始文件（图片、PDF 等），只有文本附件的内容。
- 编辑过的消息，导出里可能同时包含多个版本，按原顺序全部显示。
