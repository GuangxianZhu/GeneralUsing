有人问了一个关于功能的问题,帮我查清楚实际的动作。

- 问题:【原文贴在这里】
- 提问方:【客户 / 外包 / 内部】
- 机台 / 客户:【】
- 版本:【旧版 / 新版 / 不确定】
- 回复语言:【日文 / 中文】

调查内容:
1. 要求和设计:这个功能当初的要求是什么,后来有没有变更(按时间分界查老数据库和 Microsoft 365)。
2. 代码:对应分支上实际的实现,关键的条件判断、参数、时序。
3. 机台配置和 IO:这台机台上相关的配置值和 IO 点。
4. 要求、设计、代码三者有没有不一致。

报告之外再给我:
- 一段可以直接回复提问方的草稿,用上面指定的语言,只写对方需要知道的内容。
- 回复前我应该自己再确认的地方。
