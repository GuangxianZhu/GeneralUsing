按 `.github/source-map.md` 逐个测试每个信息源能不能访问。

每个来源只做一次最小的只读操作:
- 数据库:连接后查一下有哪些表
- VSS:对配置路径执行一次 Dir
- SVN:`svn info` 加 `svn list`
- Git:`git fetch` 加 `git branch -r`
- Work IQ:问一个简单问题
- 手册位置:列出顶层目录

完成后:
1. 把地图里每个来源的「状态」改成「已确认」或「失败」。
2. 给我一张表:来源、结果、失败时的错误信息、需要我做什么(装工具、申请权限、补路径)。
3. 地图里还空着的 `<...>`,能从环境里查出来的(表名、分支名、目录结构)直接补上,补了哪些告诉我。
