description: 扫描手册存放位置,生成索引 CSV
---

给散落在服务器上的手册建一份索引。

1. 写一个 Python 脚本,扫描 `.github/source-map.md` 第 8 节列出的位置。
2. 只读取文件信息,不打开内容,不复制文件:完整路径、文件名、扩展名、大小、修改时间。
3. 只收文档类文件:pdf、doc、docx、xls、xlsx、ppt、pptx、txt。
4. 结果写到 `work/_index/manuals.csv`(UTF-8 带 BOM)。
5. 扫描中途断了能接着跑,访问不了的目录记到 `work/_index/skipped.txt`。

索引建好后,根据文件名和所在目录加一列「推测分类」(操作手册、维护手册、规格书、图纸、其他),并给我一份概要:
- 各位置的文件数量
- 各分类的数量
- 文件名相同但路径不同的重复文件
