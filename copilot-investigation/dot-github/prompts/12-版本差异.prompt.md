description: 比较同一功能在两个版本或两个分支上的差异
---

比较一个功能在两边的差异。

- 功能:【】
- A:【版本 / 分支 / 机台】
- B:【版本 / 分支 / 机台】
- 关心的点:【动作顺序 / 参数 / 报警条件 / IO / 全部】

调查内容:
1. 两边各自取得对应的代码,找到这个功能的入口和主要处理。
2. 逐项比较:动作顺序、条件判断、参数和默认值、报警、用到的 IO。
3. 下位层的共通函数:两边调用的是不是同一个实现,有没有一边改过。
4. 差异对应的要求或变更记录(有的话)。

报告里给我:
- 差异一览表:项目、A、B、两边的代码位置、对应的变更记录。
- 相同的部分用一两句话带过。
- 哪些差异会影响使用者看到的动作,哪些只是内部写法不同。
